# Car Cam III
AML mod for GTA III Android: lower car camera (San Andreas style).

Config (`CarCamIII.ini`): `Enabled`, `HeightDrop` (metres, default 0.8), `LookDown` (metres, default 0.6), `MinAboveCar` (default 0.8).
Bigger `HeightDrop` = camera lower; bigger `LookDown` = camera looks lower at the car. Log: `CarCamIII.log`.
Build: replace `src/main.cpp` in your AML template repo or push this folder; GitHub Actions builds `libCarCamIII.so`.
